## Adding a New Application Policy

To publish a privacy policy for a new BoldKiteLabs application:

1. Create a directory matching the application's slug (e.g., `my-app/`).
2. Add `my-app/index.html` and `my-app/PRIVACY_POLICY.md`.
3. Add an entry to [index.html](./index.html) and the table above.
4. Commit and push to `main`. The policy will be live at `https://boldkitelabs.github.io/privacy-policies/my-app/`.
